Options d'extraction

Blocs (--chunks) Un extracteur LLM par bloc de données (découpe le texte, pas le prompt). Décocher un bloc le retire entièrement du résultat.
Options Désactive la validation factuelle LLM (un prompt VRAI/FAUX qui vérifie chaque triplet contre le texte source). Extraction plus rapide, mais rien ne filtre plus les hallucinations. Affiche la réponse brute du LLM pour chaque bloc dans le journal du job — utile pour diagnostiquer un problème de prompt ou de format JSON. Envoie le texte entier de l'article à chaque prompt au lieu du texte découpé par section (abstract/méthode/résultats…). Désactive le routage par section : plus lent, plus de bruit — surtout utile pour comparer les deux approches (A/B). Désactive la recherche de métadonnées par DOI (CrossRef/OpenAlex) qui complète le bloc bibliographic (titre, auteurs, année, revue, pays). Utile hors ligne, ou pour une extraction plus rapide.
